# Arsip utilitas SQLite

`cleanup_demo_sqlite.py.txt` menyimpan kode pembersihan demo lama sebagai referensi, bukan perintah yang dapat dijalankan. Path relatif dan SQL di dalamnya berasal dari struktur SQLite terdahulu. Runtime sekarang memakai MySQL; jangan menggunakannya untuk membersihkan database aktif atau cadangan sumber.

Alat migrasi yang berlaku berada di `../migrate_sqlite_to_mysql.py`. Pengelolaan akun dan soal aktif dilakukan lewat panel admin.
