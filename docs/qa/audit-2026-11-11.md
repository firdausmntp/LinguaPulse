## 2. Resolusi Keamanan & Pencegahan Kebocoran Data Soal (JSON Data Leakage)

Sebelumnya terdapat celah di mana kunci jawaban (`answer`, `correct_answer`), pembahasan (`explanation`), transkrip audio Listening (`passage`), dan referensi kecerdasan buatan (`sample_ai_reference`) terbaca di tab Network browser saat daftar soal dimuat. Masalah ini telah diselesaikan secara tuntas:

1. **Endpoint Contoh Soal Beranda (`/api/sample-question`):**
   - Respon `GET /api/sample-question` kini hanya mengirimkan `id`, `title`, `prompt`, dan `options`. Kunci dan pembahasan tidak lagi dikirimkan di awal.
   - Pengecekan jawaban dipindahkan ke endpoint `POST /api/sample-question` on-demand saat pengunjung memilih opsi.
2. **Endpoint Latihan Bebas (`/api/practice/question`):**
   - Respon `GET /api/practice/question` telah disanitasi: kunci jawaban, pembahasan, dan transkrip audio listening dihapus sepenuhnya sebelum dikirim ke peserta.
   - Evaluasi jawaban dilakukan melalui `POST /api/practice/question` saat tombol "Periksa jawaban" ditekan, mengembalikan status benar/salah serta pembahasan secara aman.
3. **Endpoint Sesi Ujian Aktif (`/api/exam/start` dan `/api/exam/resume`):**
   - Fungsi `public_bank` di `questions/loader.py` menyaring seluruh sub-array soal (`listening.questions`, `grammar_mc`, `grammar_rewrite`, `reading.questions`, dan `writing_tasks`).
   - Atribut sensitif (`answer`, `correct_answer`, `explanation`, `folder_file`) dibersihkan dari payload sesi. Kunci jawaban tetap tersimpan aman di server dalam tabel `exam_attempts`.
4. **Tabel Bank Soal Admin (`/api/questions` & `/api/admin/questions`):**
   - Daftar ringkasan tabel bank soal (`all_questions`) hanya memuat metadata publik (`question_id`, `section`, `question_type`, `title`, `prompt`, `is_active`, `audio_url`).
   - Pengambilan kunci dan pembahasan lengkap untuk keperluan pengeditan dilakukan secara on-demand per soal melalui endpoint `GET /api/admin/questions?id=<ID>`.
   - Toggle status aktif soal hanya memerlukan payload minimal (`question_id`, `is_active`, `mode: 'toggle'`) tanpa membeberkan kunci soal di tabel.

## 3. Ekstraksi Engine Telemetri Menjadi Library Python Mandiri

Sesuai arsitektur modular riset, logika inferensi telemetri integritas pengerjaan telah dipisahkan menjadi library Python lokal berstandar *pip*:

- **Lokasi Package:** `packages/proctor_telemetry/`
- **Konfigurasi Build:** `pyproject.toml` dengan metadata `proctor-telemetry` (versi `0.1.0`).
- **Modul Internal:**
  - `features.py`: Perhitungan statistik (`median`, `iqr`, `percentile`, `sigmoid`, entropi Shannon $H$, dan 18 fitur fusi $x_k, x_f, x_h$).
  - `rules.py`: Evaluasi heuristik baseline integritas ujian.
  - `models.py`: Model ansambel XGBoost representation, 1D-CNN sequential anomaly score, dan 7 skenario pengujian ablasi.
  - `engine.py`: Entry point tunggal `extract_features_and_predict`.
- **Integrasi Backend:** `backend/telemetry_engine.py` berfungsi sebagai bridge penghubung yang rapi dengan mekanisme *graceful local fallback*.

## 4. Generator Audio Listening Autentik (Microsoft Edge Neural TTS)

Telah disediakan perangkat pembantu di `scripts/generate_toefl_audio.py` untuk memproduksi rekaman audio Listening TOEFL berkualitas studio:

- **Preset Suara:**
  - Narator instruksi tes: `en-US-GuyNeural` dan `en-US-AndrewNeural` (aksen General American netral, tegas, dan berwibawa).
  - Kuliah / monolog akademik wanita: `en-US-JennyNeural` dan `en-US-AriaNeural`.
- **Pengaturan Tempo Pengerjaan:** Parameter kecepatan default `-8%` (sekitar 0.92x) untuk memastikan kejelasan artikulasi dan tempo tenang standar TOEFL ITP/iBT.
- **Audio Sampel Terverifikasi:** `frontend/media/listening/sample-instruction.mp3`.
